# Dif app icon

The source image is `Dif-icon-master.png`. The macOS icon sizes in `Dif/Assets.xcassets/AppIcon.appiconset` were resized from it with `sips`.

Generated with the built-in `image_gen` tool for the previous name, DiffQuill. Final prompt:

> Use case: logo-brand. Asset type: finished macOS application icon for an offline text diff app named DiffQuill. Create a single square 1024×1024 icon artwork. A clean rounded-square deep indigo tile, with genuine transparent pixels outside the rounded-square silhouette. Centered on the tile: two simple ivory document columns side by side, joined by one elegant ivory quill nib/stem shape. The left document has one short coral-red horizontal removal stroke; the right document has one short mint-green horizontal addition stroke. Minimal flat vector-like geometry, crisp high-contrast edges, balanced spacing, strong silhouette legible at 16 px, subtle depth only if it improves clarity. No words, no letters, no watermark, no mockup, no surrounding scene, no extra symbols.
